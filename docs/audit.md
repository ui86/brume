## 第三轮按优先级修复

| 优先级 | 已完成的处理 | 验证重点 |
| --- | --- | --- |
| 中 | UDP 任一地址族返回可用地址后立即建流，另一族继续在 10 秒 DNS 总预算内查询；失败后保留晚到地址供后续数据报回退 | 两族分别无响应、晚到另一族、关闭时取消查询；等待任务保留流许可，旧 worker 不能覆盖新流偏好或重新插入已淘汰目标 |
| 中 | 客户端改用可取消的异步 DNS，最多 16 个解析工作槽、32 个 DNS TCP 套接字；传输清理完成后才归还配额，保留工作槽 TTL 缓存和 60 秒配置刷新 | 超时后客户端仍存活时 TCP 查询连接关闭，随后未缓存查询恢复；并发排队取消、配置代数切换、真实套接字上限与缓存复用 |
| 中 | 系统 DNS 配置缺失或不可读时仍允许 hosts 命中；网络域名保留原配置错误，不暗中使用公共 DNS | 无配置 Alpine 中复现并修复，覆盖缺失、权限和非法配置错误 |
| 中 | 同一上游内部完成 UDP 截断到 TCP 的回退，避免多个 DNS 同时截断时误报失败 | 并行双上游同时截断、TCP 回复与 TTL 缓存、TCP 再次截断时及时返回错误 |
| 中 | 修改和升级的日志临时文件模板改为以随机占位符结尾，兼容 BusyBox 的 `mktemp` | Alpine 真实复现旧模板失败；两个原有回归增加兼容限制，修复后均通过 |
| 低 | TCP 每方向缓冲由固定 64 KiB 改为初始 8 KiB，满读时按需增长至 64 KiB；UDP 回复缓冲在套接字可读后分配 | 小流量、连续大流量、半关闭和空闲超时行为，大 UDP 报文不截断 |
| 低 | 白名单加载时按地址族原地排序并合并重叠、相邻范围；不超过 4 个范围直接比较，其余二分查找 | 全部前缀长度、空名单、IPv4 映射 IPv6、宽 IPv6 网段及确定性逐项算法等价回归 |

白名单同机对照中，4096 个离散网段的末尾命中和未命中从约 3.6 微秒降至约 12 纳秒，小名单维持低开销。256 个连续网段合并为 1 个 IPv4 范围；4096 个离散 IPv4 网段的容器负载从 72 KiB 降至 32 KiB。TCP 双向初始缓冲合计 16 KiB，按需最多 128 KiB；无回复的 UDP 流不再预留约 64 KiB 回复缓冲。这些容量不含套接字、任务和分配器开销，仍需在目标 Linux 机器测量实际负载与常驻内存。对照条件及数据见[性能说明](performance.md)。

## 仍存在的边界

- 拒绝端口 `0` 是明确的安全兼容性取舍：只发送该端口的通用客户端会失败，NAT 改写 UDP 来源端口也无法匹配。兼容这些场景需要独立关联中继端口及对应的防火墙规划。
- 客户端读取系统 DNS、搜索域和 hosts 配置，但不执行系统的 NSS、mDNS、LLMNR、NRPT、按接口拆分 DNS 或系统 DoH 策略；依赖这些机制的名称需要显式 IP、hosts 或可直接访问的 DNS 记录。
- 修改失败后的系统配置和服务恢复是尽力执行；恢复失败时保留私有备份和日志，仍需管理员根据日志处理。防火墙已在隔离 Linux 环境验证，真实 systemd 服务事务仍待 CI 执行。
- 默认空白名单和空认证允许所有来源，用户名密码按 SOCKS5 标准明文传输；这些是现有配置与协议行为，部署方式见[使用说明](usage.md)。
