# Brume 1.0.10

本次补丁版本主要降低重复建连、数据转发和间歇活跃连接的资源开销。

## 更新内容

- 普通 HTTP 转发复用上游连接，限制空闲连接总数和每个目标的空闲数量，完整读取响应后才归还连接。
- UDP 已有流在可立即发送时直接转发，减少负载复制和逐包任务调度。
- UDP 回复使用共享缓冲池，总缓冲容量限制为约 2 MiB；TCP 扩容缓冲连续 1 秒未读到数据后恢复为初始大小。
- 客户端检查系统 DNS 配置时，内容未变则保留解析缓存；系统配置读取使用有并发限制的阻塞任务。
- TCP 空闲超时复用定时器，减少每个转发数据块的活动通知。
- 新增本地安装脚本 `install-local.sh`，已有二进制时无需联网下载，兼容 systemd、OpenRC、SysVinit 及无服务管理器的运行环境。

## 性能验证

Linux ARM64 本机五轮对照中，普通 HTTP 的 16 路并发吞吐提高约 41%，UDP 直接发送的代理 CPU 时间减少约 30%。256 个间歇活跃 UDP 流的 RSS 减少约 74%，256 条 TCP 连接传输后的 RSS 减少约 40%。这些结果来自不同的指定负载，收益不可相加，也不代表公网性能。

HTTP 分散写因未测出稳定收益已回退。TCP 超时通知优化按 CPU 收益保留，吞吐和尾延迟未全面改善。完整条件、原始数据和取舍见[性能优化记录](../optimizations.md)。

版本更新前的完整验证包括 91 项单元测试、1 项命令行集成测试、格式及 Clippy 检查、Linux 真实描述符耗尽与恢复，以及 Windows 交叉编译检查；对应 GitHub CI 也已通过。

## 安装与部署

- Linux amd64、arm64 安装包包含静态链接程序、本地安装脚本及文档，可使用仓库一键安装脚本更新。
- Docker 镜像标签为 `ghcr.io/ui86/brume:1.0.10`，同时提供 `linux/amd64` 和 `linux/arm64`；发布流程校验后更新 `latest`。
